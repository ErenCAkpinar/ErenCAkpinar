# Hi, I'm Eren 👋

Final-year Computer Engineering student at Eastern Mediterranean University (Cyprus), expected to graduate in 2027. I build research systems for algorithmic trading and AI-assisted decisions, mostly in Python and Rust, and I document what they actually do, including what didn't work.

## Selected projects

**[BreakoutBot](https://github.com/ErenCAkpinar/BreakoutBot)** · [live record](https://breakoutbot.dev)  
Regime-aware crypto breakout bot running 24/7 as a public simulation on live Binance Futures prices: fixed-dollar risk, drawdown kill-switches, a written postmortem, and an experiment (with decision rules written before collecting data) testing whether an LLM reviewer that can veto entries improves results.

**[CryptoSentinelTrader](https://github.com/ErenCAkpinar/CryptoSentinelTrader)**  
Python + Rust research system: a Rust engine streams Binance Futures data and computes indicators and anomaly scores; a Python pipeline makes decisions and manages paper positions under hard risk limits.

**[AI_Hedge_Fund](https://github.com/ErenCAkpinar/AI_Hedge_Fund)**  
Multi-agent swing-trading pipeline for US stocks and ETFs: rule-based agents, quant filters, an LLM approval step and Alpaca paper trading, with a backtest documented alongside its limits.

**[LuxeStay](https://github.com/ErenCAkpinar/LuxeStay)** · [live demo](https://erencakpinar.github.io/LuxeStay/luxestay_website/home/html/index.html)  
University team project (CMPE312): I owned the UI/UX, 20+ Figma screens implemented as a responsive HTML/CSS site.

Also: [quant-trade-first-project](https://github.com/ErenCAkpinar/quant-trade-first-project), an ensemble equities strategy scaffold with a transaction-cost-aware backtest engine (spread, market impact, borrow costs) and walk-forward validation, and [quant-stock-fetcher](https://github.com/ErenCAkpinar/quant-stock-fetcher) for market-data plumbing.
